# 📊 COVID-19 Data Analysis

A Python-based data analysis project that explores real-world COVID-19 time-series data to identify trends, compare case counts across countries, and visualize the progression of the pandemic using statistical techniques and charts.

---

## 📌 Project Overview

The objective of this project is to analyze COVID-19 data from multiple countries and generate meaningful insights through data preprocessing, trend analysis, and visualization. The project calculates daily and weekly new cases, applies rolling averages to smooth fluctuations, identifies peak infection periods, and exports the processed data for further analysis.

---

## 🚀 Features

* Load real-world COVID-19 time-series data
* Clean and preprocess the dataset
* Calculate daily new COVID-19 cases
* Calculate weekly case totals
* Compute 7-day rolling averages
* Compare COVID-19 trends across multiple countries
* Detect peak daily case counts
* Calculate growth-rate trends
* Create line charts for data visualization
* Export processed data to CSV
* Save analysis charts as PNG images
